# Study Room Frontend

Frontend cua he thong dat phong hoc Study Room, duoc xay dung bang React, Vite va Bootstrap.

## Cau hinh moi truong

Sao chep file `.env.example` thanh `.env`:

```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

- `VITE_API_BASE_URL`: dia chi backend API.
- `VITE_GOOGLE_CLIENT_ID`: OAuth Client ID dung cho dang nhap Google.

## Lenh chay

```bash
npm install
npm run dev
```

## Lenh kiem tra

```bash
npm run lint
npm run build
```
